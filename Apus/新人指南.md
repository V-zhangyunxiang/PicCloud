# 新人指南

## 一、[商业化隔离红线]

1、千万千万，不能在开发包名的开发环境上，去直接依赖 qa 或 release 版本的广告库。

2、不能使用个人的 Android 手机，直接安装隔离产品的 APK，必须使用每个产品对应的隔离机，才能进行功能和广告的测试。

3、隔离机不能连接公司 WIFI 网络，只能使用手机自带的流量卡或同产品隔离机的热点。

4、广告 Demo APP 禁止在任何隔离机上联网运行。

5、AI Coding 禁止使用 Gemini。

## 产品隔离文档学习

**隔离账号(GP 开发者账号 + 广告账号)**
   每个账号至少一台独立的全新的隔离手机。
   每个账号一个独立的手机卡及多个流量卡。
   每个账号一个虚拟云主机(Windows 云电脑)，用于登录和使用开发者账号和广告账号。
   
   必须增加两步认证，包括身份验证器二维码、手机号，当有一个不好使时可以切换另一个。身份验证器只能在对应的隔离手机中使用，只允许添加该账号相关的开发者账号、广告账号、推广账号等。
   
   Android 的账号，严禁与 iOS 或其他平台共用，包括开发者账号、反馈邮箱等。
   新注册的账号，在隔离设备上登录后，养 3 天以上再提交 App 审核。

**隔离手机**
  统一连手机卡热点。
  关闭 GPS 定位。
  开启的热点名称跟账号相关。
  系统设置为英文。
  关闭 Google Play 的保护机制。
  严禁装实时验证平台的 App。

**隔离电脑**
   电脑名字不能带 APUS 或中文相关的名字。
   隔离环境下离线(断网)开发、编译、打包。
   只允许通过局域网连隔离环境的服务器。

**手机卡、流量卡**
   手机卡要独立使用，不能跟其他主体复用，禁止使用香港手机卡，流量卡用于开热点流量。
   
   新流量卡放入 iOS 手机，查看 ip 信息，确认 ip 显示的国家和卡对应的国家是否一致，确认 ip 的前三位号段与之前是否不相同。

**正式手机、开发手机和隔离手机区别是什么？**

正式手机、开发手机都是属于隔离手机，开发手机只能使用中国大陆的流量卡，正式手机使用海外的实体卡，广告 SDK 都是在正式手机上测试。

## Target 升级

升级聚合 SDK 版本、聚合 SDK 推荐的广告源 SDK 版本，讨论出广告源 SDK 版本最终使用的版本。

修改 Target 升级相关代码，解决编译问题，打出 release apk，手机时间和日期选择自动获取，清除 apk 数据，安装到 2 个 OS 版本的手机上测试广告展示情况，统计各聚合和其广告源的展示情况，填写到升级表格中，没有被测试到的广告源使用聚合平台的工具指定广告源展示，完成没有被自测覆盖的广告源测试。

注意点：
1.至少 2 个 Android OS 版本。
2.需要清缓存和强制杀死 App。

## 云控下发流程

1.数数平台【分析】- 【事件分析】- 【biz_ad_response > 触发用户数】，分组选择 3 个【版本名称】，【biz_sdk_version】，【biz_strategy_version】。 看人数最多和第二多的版本，看 diff，找人确认(商业化 RD)基于哪个策略版本(云控和内置两种)修改。
2.策略仓库或业务仓库找到该版本策略 JSON 修改(一定先改配置版本号!!!)，新版本要确认版本号有没有被占用。
3.找杰哥确认 diff 内容，没问题后加密，并把云控 JSON 放入 allAndroidCloud 工程备份，要反向解密二次验证下是否跟原始内容一致。
4.**云控**腾讯文档登记。
5.往 APUS 商业化技术群发送相关信息，通知产品上传后台，可同步私聊通知。
6.关注业务异常情况，没问题可以通知产品继续放量，第二天数数平台查看两个云控版本的 ARPU 值收益情况对比。
