新人指南

一、[商业化隔离红线]

1、千万千万，不能在开发包名的开发环境上，去直接依赖 qa 或 release 版本的广告库。

2、不能使用使用个人的 Android 手机，直接安装隔离产品的 APK，必须使用每个产品对应的隔离机，才能进行功能和广告的测试。

3、隔离机不能连接公司 WIFI 网络，只能使用手机自带的流量卡或同产品隔离机的热点。

4、广告 Demo APP 禁止在任何隔离机上联网运行。

5、AI Coding 禁止使用 Gemini。


二、[商业化Android开发的能力演进]

1、了解商业化的基本概念和基础知识，方便平时工作交流，

比如聚合、广告源、广告位、广告类型(插屏、激励、开屏、原生、Banner)、ARPU 值、eCPM、ADPV、ADPV 利用率、AIPU、广告渗透率。

2、熟悉广告 SDK 的代码，特别是广告的初始化、广告的预加载、加载、展示、点击、关闭和收入上报等流程。重点要理解广告的比价逻辑。

3、熟悉广告相关的其他知识和技术，具备基本的技术调研能力，比如归因、云控、打点上报、反编译、反射、Hook、字节码插桩等等。

4、熟悉各个商业化指标的计算方式，并能够基于数据分析平台去查询这些指标。

5、逐步掌握数据分析的能力，除了承接产品和业务团队的需求外，能主动发现问题，用数据来驱动自己负责的广告 SDK 的优化。
